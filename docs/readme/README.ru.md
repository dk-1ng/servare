Расширение для Firefox и Chromium, которое обнаруживает видео и аудио, загружаемые страницей, и позволяет сохранить их локально — прямые файлы, HLS и DASH. Вся обработка выполняется внутри браузера.

> **Статус:** в разработке (pre-alpha). Следите за прогрессом на [доске проекта](https://github.com/users/dk-1ng/projects/4) и в [milestones](https://github.com/dk-1ng/servare/milestones).

## Запланированные возможности

- Автоматическое обнаружение медиа по сетевым запросам страницы
- Прямые файлы (MP4, WebM, MKV, MP3…), HLS и DASH
- Выбор качества, аудиодорожки и субтитров
- Запись прямых трансляций (HLS)
- Извлечение аудио в MP3
- Очередь с паузой и возобновлением, в том числе после перезапуска браузера
- Локальный ремукс с помощью FFmpeg, скомпилированного в WebAssembly, — без нативного приложения, без сервера, без телеметрии
- Зеркальный режим (Firefox): повторно использует данные, уже загруженные плеером, без дополнительных запросов

## Вне рамок проекта

- **YouTube** — не поддерживается по принципиальному решению.
- **Контент с DRM** (Widevine, PlayReady, FairPlay и т. д.) — обнаруживается и отклоняется. Servare не содержит и не примет код для обхода DRM, авторизации, платного доступа или любых других технических средств защиты.

## Разработка

Требования: Node.js LTS, pnpm, FFmpeg (для генерации тестовых фикстур).

```sh
pnpm install
pnpm dev            # Chromium с автоперезагрузкой
pnpm dev:firefox    # Firefox
pnpm test           # модульные тесты
pnpm build          # production-пакеты для обоих браузеров
```

Техническая документация (на английском): [docs/design.md](../design.md). Как внести вклад: [CONTRIBUTING.md](../../CONTRIBUTING.md).
